JRRF 会場 / 公式PDFの寸法を優先した3Dモデル
2026-10-01

公式Eホール設備図2025/12版を元に作成した、配置検討用の別モデルです。
https://www.trc-event.jp/download/pdf/setsubi_e.pdf

寸法の合わせ方
・主要な壁の基準面を、幅47.520m・奥行き40.380mに合わせています。
・柱の位置は図中の寸法列から算出。横の650 / 11130 / 860 / 10870 /
  1120 / 11140 / 860 / 10890 mmの合計は47520 mmになります。
・縦の940 / 8720 / 1050 / 8960 / 1060 / 8950 / 1050 / 8720 / 930 mm
  の合計は40380 mmになります。
・柱9本の幅・奥行きはPDFの記載値を優先し、図形の比率と違うものも作り直しています。
・天井高4.000m、SWの低い天井は下面2.540m、範囲6.540×4.530m。
・東側で扉記号が描かれる4区画には、それぞれ幅1.780m×高さ2.100mの
  二枚扉の組を2組ずつ設定。西側の寸法付き搬入口は2.330×3.000mと4.100×3.400m。
・扉の記載W/Hを図の二枚扉一組の開口に適用しています。現地の有効開口の保証ではありません。

座標と単位
・3D / OBJ / JSON / CSVはメートル、DXFはミリメートル。
・元になるローカル座標は、西主壁の基準面がX=0、南主壁の基準面がY=0、床がZ=0。
・スキャン版と並べられるよう、X=-22.4382399202m、Y=-15.0224349594mだけ平行移動済み。
・形状・寸法・縮尺はPDFから作っています。スキャン版の柱中心は、この平行移動にのみ使用。
・回転や追加の拡大縮小はありません。

納品ファイル
JRRF_PDF_venue.blend
  編集用Blenderファイル。床・壁・柱・入口・低い天井・防災設備配置範囲を別コレクションに分離。
  「10_Scan_model_reference_hidden」に前回のスキャン版モデルを非表示で同梱しています。
  比較する場合、このコレクションを表示し、PDF側のコレクションを適宜切り替えてください。
  公開配布版には元PDF画像を含めていません。公式配布URLを参照してください。
  「07_Door_leaves_optional_hidden」は任意表示の扉面、「08_Main_ceiling_optional_hidden」は天井面。
  標準の閉じたポリゴンメッシュです。
JRRF_PDF_venue.glb
  PDF版のみの軽量3D交換モデル。glTF標準Y-up / メートル。
JRRF_PDF_venue.obj / JRRF_PDF_venue.mtl
  OBJ交換モデル。Z-up / メートル。2ファイルを同じフォルダに置いてください。
JRRF_PDF_plan_mm.dxf
  PDF版の2D図面。寸法付き柱、壁、床、開口、防災設備配置範囲、低い天井をレイヤー分け。
JRRF_PDF_plan.png / JRRF_PDF_preview.png
  平面図と全体プレビュー。
JRRF_PDF_vs_scan_plan.png
  同じ座標に置いたPDF版とスキャン版の平面図。モデル間の違いを確認できます。
JRRF_PDF_columns_metres.csv / JRRF_PDF_venue.json
  柱寸法・位置、寸法列、補間の根拠などの数値データ。
public_native_validation.json / public_export_validation.json / export_validation.json
  保存後の再読み込み、寸法、閉じた形状、交換形式での保持の確認結果。

図面から補った部分
・寸法未記載の壁厚や細かい凹凸は、補正したPDFの図形に従っています。
・柱の面取りはPDF図形の相対比率。面取り寸法自体の明示はありません。
・寸法未記載の北・南の搬入口や非常口は、図面上の隙間として保持し、開口高さを確定していません。
・SWの無記名の白い部分はアクセス用の区画として床を分離しています。範囲・用途の解釈は暫定です。
・低い天井の位置は隣接壁の図形から。厚み0.15mは表示用で、実測値ではありません。
・照明、天井格子、小さい設備などは詳細には再現していません。
・薄緑の床面はPDFの防災設備配置範囲です。出展物を置かない範囲として区別してください。
・床輪郭の面積約1882.6m²はこのモデルの図形面積。公式の1984m²とは定義をそろえていません。

検証
・Blenderファイルを保存後に開き直し、基準寸法、9本の柱の寸法、8組の1.780×2.100m開口、
  低い天井の6.540×4.530m・下面2.540mを確認しました。
・納品モデルの88メッシュ部品は閉じた形状で、正の体積を確認。
・GLBとOBJも再読み込みし、柱寸法、低い天井の高さ、座標範囲を確認しました。
・検証はモデルが図面の記載寸法を保持していることの確認で、実際の会場の計測精度の保証ではありません。
